# psyskills Plugin — Design Spec

**Date:** 2026-04-28  
**Status:** Approved

## Overview

Claude Code плагин для психологов-практиков. Поддерживает рабочий цикл: анализ транскрипта сессии → доработка концептуализации → формирование стратегии следующей сессии → супервизия.

Начальные модальности: КПТ и ОРКТ. Архитектура допускает добавление новых модальностей без изменения скиллов.

## Architecture

Вариант: модульные независимые скиллы с общим форматом файла клиента.

Каждый скилл вызывается отдельно, читает/пишет `clients/имя.md`, использует reference-файлы нужной модальности.

## Skills

| Скилл | Входные данные | Действие |
|-|-|-|
| `psy:conceptualize` | client.md + транскрипт | Анализирует транскрипт, предлагает обновление концептуализации (BASIC ID) |
| `psy:goals` | client.md + транскрипт | Уточняет/формулирует контракт и цели |
| `psy:strategy` | client.md | Строит стратегию следующей сессии на основе концептуализации и целей |
| `psy:supervise` | client.md + транскрипт | Оценивает концептуализацию, контракт/цели, стратегию, работу терапевта |

## Workflow

```
После сессии:
  транскрипт.txt → /psy:conceptualize имя [модальность]
                 → /psy:goals имя

До следующей сессии:
                 → /psy:strategy имя

Супервизия (когда нужна):
  транскрипт.txt → /psy:supervise имя
```

## Client File Format

`clients/имя.md`:

```markdown
---
modality: cbt
name: идентификатор
---

## Концептуализация (BASIC ID)
<!-- Поведение, Аффект, Ощущения, Образы, Когниции, Межличностные отношения, Биология -->

## Контракт и цели

## Стратегия

## История сессий
```

Модальность из frontmatter — дефолт. Переопределяется аргументом: `/psy:strategy имя orct`.

## Supervisor Output Format

```markdown
## Супервизия — [имя] — [дата]
### Концептуализация: X/10
### Контракт и цели: X/10
### Стратегия: X/10
### Работа терапевта: X/10
### Комментарии и рекомендации
```

## Transcript Input

Транскрипт передаётся как путь к файлу: `/psy:conceptualize имя transcript.txt`. Скилл читает файл. Если путь не указан — скилл просит вставить текст в чат.

## Constraints

- Reference-файлы изначально пустые; пользователь наполняет материалами из лекций
- Транскрипты не хранятся в проекте — приходят извне готовыми
- Скиллы предлагают изменения, пользователь подтверждает перед записью в client.md

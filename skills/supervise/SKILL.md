---
name: psy:supervise
description: Supervise a therapy session by evaluating conceptualization quality, contract/goals, strategy, and therapist performance. Produces a structured report with scores and recommendations.
---

Проводи супервизию терапевтической сессии — оценивай концептуализацию, контракт/цели, стратегию и работу терапевта. Опирайся на фреймворк школы (Тема 11-14).

## Входные данные

Аргументы: `/psy:supervise <имя-клиента> [путь-к-транскрипту] [модальность]`

- `имя-клиента` — обязательный
- `путь-к-транскрипту` — необязательный. Если не указан — попроси вставить текст
- `модальность` — необязательный

## Процедура

1. **Прочитай файл клиента** `clients/<имя-клиента>.md`

2. **Определи модальность**

3. **Прочитай оба reference-файла:**
   - `references/lazarus-basic-id.md`
   - `references/cbt.md` или `references/orct.md`

4. **Получи транскрипт** (из файла или попроси вставить)

5. **Проведи оценку по четырём осям:**

---

### Ось 1: Концептуализация (0–10)

Критерии:
- Зафиксирована жалоба (неудовлетворённость + несостоятельность)?
- Проблема сформулирована совместно с клиентом (трудность с... / недостаток... / неспособность...)?
- Охвачены все релевантные модальности BASIC ID?
- Построены связи между модальностями?
- Внутренняя согласованность концептуализации?
- Подкреплена конкретными данными из сессий?
- Включена дополнительная информация (триггеры, ресурсы, уязвимости, исключения)?
- Концептуализация обновляется по мере работы?

---

### Ось 2: Контракт и цели (0–10)

Критерии (6 критериев школы):
- Позитивность — цель направлена на достижение, а не на избегание?
- Реалистичность — цель достижима?
- Без третьих лиц — цель о клиенте?
- Достижимость средствами психотерапии — работа с мыслями/поведением/состоянием?
- Конкретность — есть критерии достижения?
- Понятность — абстрактные понятия расшифрованы?
- Цель прошла три состояния (мутная → средняя → чёткая)?
- Проверка экологичности проведена?
- В КПТ: SMART-формулировка, связь с мишенями
- В ОРКТ: цель в словах клиента, позитивная, наблюдаемая

---

### Ось 3: Стратегия (0–10)

Критерии:
- Стратегия вытекает из концептуализации?
- 4 шага присутствуют: рамка → мишени → приоритет → интервенции?
- Мишени определены (что ухудшает + что улучшает)?
- Приоритет обоснован?
- Интервенции соответствуют модальности (КПТ/ОРКТ)?
- Структура сессии соблюдена (7 элементов)?
- Есть домашнее задание?
- Гибкость — стратегия корректировалась при необходимости?

---

### Ось 4: Работа терапевта в сессии (0–10)

Критерии:
- Соблюдена структура сессии (контакт → обновление → ДЗ → рамка → работа → ДЗ → итоги)?
- Качество терапевтического альянса (сотрудничество, эмпатия, аутентичность)?
- Точность и уместность интервенций (каждая обоснована концептуализацией)?
- Работа с динамикой отношений (идеализация, скепсис, разочарование, агрессия)?
- Следование подходу (КПТ: когнитивная работа, домашнее задание; ОРКТ: фокус на решении, комплименты)?
- Сбор обратной связи (ORS/SRS или шкалы)?
- Терапевт не переходит к вмешательствам до согласования цели?

---

6. **Выдай структурированный отчёт:**

```
## Супервизия — [имя клиента] — [дата]

### Концептуализация: [X]/10
[3-5 предложений: что хорошо, что можно улучшить, конкретные примеры из client.md]

### Контракт и цели: [X]/10
[3-5 предложений: какие критерии выполнены / не выполнены, предложения]

### Стратегия: [X]/10
[3-5 предложений: логика стратегии, обоснованность интервенций, структура сессии]

### Работа терапевта: [X]/10
[3-5 предложений: конкретные примеры из транскрипта — что сработало, что можно иначе]

### Итого: [сумма]/40

### Сильные стороны
- [что терапевт делает хорошо — конкретно]

### Приоритетные рекомендации
1. [самое важное для развития — конкретно и с примером]
2. ...
3. ...
```

7. **Спроси:** "Сохранить отчёт в историю сессий `clients/<имя>.md`?"

8. **На подтверждении:** добавь полный отчёт в секцию `## История сессий`.

## Важно

- Оценки обоснованы конкретными примерами из транскрипта или client.md — без примера нет оценки
- Тон: поддерживающий и конструктивный — это супервизия, а не критика
- Сильные стороны выделяй наравне со зонами роста
- Если reference-файл пустой — оценивай по базовым знаниям о подходе и предупреди об этом
- Рекомендации формулируй конкретно: не «улучшить работу с целью», а «переформулировать цель из негативной в позитивную, убрав "не хочу бояться", добавив желаемое состояние»

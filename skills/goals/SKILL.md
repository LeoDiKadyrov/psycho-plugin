Уточняй и формализуй терапевтический контракт и цели клиента. Используй фреймворк школы: 6 критериев цели, три состояния цели, BASIC ID как конструктор, экологичность.

## Входные данные

Аргументы: `/psy:goals <имя-клиента> [путь-к-транскрипту] [модальность]`

- `имя-клиента` — обязательный
- `путь-к-транскрипту` — необязательный. Если не указан — работаем с тем, что есть в client.md (ревью существующих целей)
- `модальность` — необязательный

## Процедура

1. **Прочитай файл клиента** `clients/<имя-клиента>.md`

2. **Определи модальность** — из аргумента или frontmatter

3. **Прочитай reference-файл** по модальности (`references/cbt.md` или `references/orct.md`) — раздел о целеполагании и контракте

4. **Если транскрипт предоставлен:**
   - Прочитай транскрипт (из файла или попроси вставить)
   - Извлеки всё, что связано с запросом, целями, пожеланиями, ожиданиями клиента
   - Отдели жалобу (неудовлетворённость + несостоятельность) от запроса (что хочет получить)

5. **Оцени текущее состояние цели** по трём уровням:
   - **Мутная** — негативные формулировки («не хочу бояться»), третьи лица, жалобы
   - **Средняя** — нет негатива, но нет конкретики
   - **Чёткая** — вычищена по 6 критериям, пригодна для контракта

6. **Проверь цель по 6 критериям:**
   - ✅ **Позитивность** — «хочу уметь» вместо «не хочу бояться»
   - ✅ **Реалистичность** — достижимо в условиях жизни клиента
   - ✅ **Без третьих лиц** — цель о клиенте, не о поведении других
   - ✅ **Достижимость средствами психотерапии** — изменения мыслей/поведения/состояния (не: деньги, работа, партнёр)
   - ✅ **Конкретность** — понятно, по каким признакам цель достигнута
   - ✅ **Понятность** — абстрактные слова расшифрованы («что для тебя значит "быть увереннее"?»)

7. **Если цель мутная — уточни через BASIC ID целевого состояния:**
   Задай вопросы о том, как будет, когда цель достигнута:
   - C: «Какие мысли будут у тебя, когда цель достигнута?»
   - A: «Что будешь чувствовать?»
   - S: «Как это будет проявляться телесно?»
   - B: «Что будешь делать иначе? Как другие это заметят?»
   - I: «Какой образ возникает?»

   Для ОРКТ: вопрос о чуде («Представь, ночью произошло чудо...»), шкалирование.

8. **Проверка экологичности** (если цель готова):
   «Представь, что цель уже достигнута. Что меняется в жизни? Как реагируют близкие? Какие перспективы открываются / закрываются?»
   Если дискомфорт — прояснять дополнительно.

9. **Проверь соответствие КПТ/ОРКТ:**
   - КПТ: SMART + связь с концептуализацией (мишени)
   - ОРКТ: позитивная формулировка, слова клиента, наблюдаемое поведение

10. **Представь анализ:**

```
## Анализ контракта и целей

### Текущая цель / запрос
[что зафиксировано сейчас в client.md]

### Из транскрипта (если предоставлен)
[жалоба / запрос / ожидания клиента — цитаты]

### Состояние цели
[Мутная / Средняя / Чёткая]

### Не пройденные критерии
[какие из 6 критериев не выполнены и почему]

### Предлагаемая формулировка

#### Запрос клиента
[в словах клиента]

#### Согласованные цели терапии
1. [позитивно, конкретно, достижимо]
2. ...

#### Критерии достижения
- [наблюдаемые признаки]

#### Терапевтическая цель (для себя, клиенту не сообщается)
[в клинических терминах — мишени работы]
```

11. **Спроси подтверждение:** "Обновить секцию 'Контракт и цели' в `clients/<имя>.md`?"

12. **На подтверждении:** обнови секцию `## Контракт и цели`. Добавь запись в историю.

## Важно

- В КПТ цели SMART + связаны с BASIC ID (мишени)
- В ОРКТ цели в позитивных терминах, в словах клиента, с наблюдаемыми признаками
- Никаких вмешательств до согласования цели — «пока цель не поставлена, никаких вмешательств»
- Терапевтическая цель (для заметок терапевта) ≠ цель для клиента
- Цель не статична — отслеживай динамику её изменения в ходе терапии
- Долгосрочная цель → ставь промежуточные контракты на отдельные области
